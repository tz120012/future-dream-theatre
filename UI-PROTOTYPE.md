# 未来梦想剧场

## 页面原型说明

本文档是 MVP 的低保真页面原型。页面以课堂模式为主，默认在 1280x720 的笔记本屏幕上全屏使用。所有儿童页面只保留一个主要动作，老师操作集中在顶部或会话结束页面。

## 1. 页面地图

~~~text
入口
 ├─ 课堂模式
 │   ├─ 课堂设置
 │   ├─ 设备检查
 │   ├─ 儿童欢迎
 │   ├─ 梦想访谈（问题 1-3）
 │   ├─ 照片选择 / 拍照
 │   ├─ 图片生成
 │   ├─ 梦想卡预览
 │   ├─ 未来的自己
 │   └─ 老师结束页 -> 下一位 / 下载 / 删除
 └─ 家庭模式
     ├─ 家长确认
     ├─ 儿童欢迎
     └─ 复用课堂中的儿童流程
~~~

## 2. 视觉方向

- 明亮、温和、易辨认的颜色。
- 背景保持干净，避免复杂装饰影响注意力。
- 儿童页面使用大字号和大面积操作区域。
- 主按钮固定在底部或右下角，位置不随内容变化。
- 录音、拍照、生成等状态使用图形加文字同时提示。
- 卡片圆角不超过 8px，保持清晰和稳定。
- 图片生成结果占据页面主要区域。

## 3. 全局结构

~~~text
┌──────────────────────────────────────────────────────────────┐
│ 未来梦想剧场                    课堂模式   第 2 位   [老师设置] │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                      当前儿童体验区                           │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 状态提示                                      [返回] [继续]    │
└──────────────────────────────────────────────────────────────┘
~~~

儿童体验过程中隐藏不必要的设置，只保留当前步骤、状态和主要动作。

左上角图标在所有页面打开全局设置抽屉，包含语音识别方式、Whisper 模型、对话服务、图片生成服务、语音播报和临时会话保留时间。硅基流动共用一把 API Key，聊天模型和图片模型单独配置。

- 扬声器不可用：显示文字，并允许继续体验。

## 8. 页面 05：梦想访谈

~~~text
┌──────────────────────────────────────────────────────────────┐
│                 你最喜欢做什么，或者帮助谁？                   │
│                                                              │
│                    [引导员头像 / 状态]                         │
│                                                              │
│                 ┌────────────────────────┐                     │
│                 │  点击这里开始录音      │                     │
│                 └────────────────────────┘                     │
│                                                              │
│ 你也可以选择： [帮助小动物] [发明东西] [探索太空] [我还不知道]   │
│                                                              │
│ 问题 1 / 3                                [跳过] [老师代答]     │
└──────────────────────────────────────────────────────────────┘
~~~

### 状态

- 等待回答：显示“开始说话”按钮。
- 正在录音：持续收集孩子的回答，显示“完成并识别”按钮和录音状态；不会因为短暂停顿自动结束。
- 正在理解：录音上传到本机 Whisper 服务，显示简短等待提示。
- 已听到：显示系统复述，提供“重新说一次”。
- 无法识别：提供点击选项、重试和老师代答。

默认使用本机 Whisper：浏览器只通过 MediaRecorder 录音，录音在本机 API 完成转写后删除；首次使用可能需要等待 Whisper 模型下载。若老师在全局设置中选择浏览器识别，则改用浏览器 SpeechRecognition，服务可用性和隐私处理取决于浏览器。

│                      想象中的未来自己                          │

│                 [梦想卡人物图像]                               │
│                                                              │
│        “你好，我是想象中的未来的你。你想聊些什么？”            │
│                                                              │

- 每轮显示孩子的语音转写或文字，以及未来自己的回复。
- 孩子可以继续追问；使用在线模型时，先显示本次体验的文字数据确认。
- 文字和语音都出现“想象中的未来自己”提示。
- 回答超出主题时，未来自己回到鼓励和想象的问题。

### 关键规则

- 下载只下载老师选择的作品，不默认下载原始照片或录音。

## 15. 页面验收清单

- 老师可以从入口到设备检查，不超过 3 个主要操作页面。
- 儿童每个页面只有一个主要动作。
- 课堂主流程不需要输入姓名或创建账号。
- 麦克风、摄像头、生成和保存状态始终可见。
- 任何失败状态都有重试、跳过或老师代答路径。
- 进入下一位前，上一位的照片、录音、文字和图片均被清理。
- 页面在 1280x720 屏幕上不出现滚动遮挡关键按钮。

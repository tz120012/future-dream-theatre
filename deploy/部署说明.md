# 未来梦想剧场 · 部署说明

> 这份文档是给"装软件的人"看的，不需要懂编程。
> 全程三步：**装 Docker → 拷文件夹 → 双击一键部署**。
> 装好之后，老师上课只需要打开浏览器输入一个网址。

---

## 0. 先确认目标电脑够用

| 项目 | 要求 | 怎么确认 |
| --- | --- | --- |
| 系统 | Windows 10 64 位（建议 22H2 及以上）或 Windows 11 | 设置 → 系统 → 关于 |
| 内存 | 建议 8 GB 以上（4 GB 能跑但语音识别会慢） | 任务管理器 → 性能 |
| 硬盘 | 至少 10 GB 空闲 | 此电脑 → 查看 C 盘 |
| 虚拟化 | BIOS 里开启 VT-x / AMD-V | 任务管理器 → 性能 → CPU，看"虚拟化：已启用" |
| 网络 | 部署时联网（下载 Docker），日常使用可断网 | — |

> 幼儿园教室的常见笔记本（i5 / 8G / 核显）完全够用。语音识别在 CPU 上跑，
> 一句话大约 0.5 秒出结果（实测 i5 CPU，base 模型）。

## 1. 安装 Docker Desktop（只需一次）

1. 打开 <https://www.docker.com/products/docker-desktop/>，点 **Download for Windows**。
2. 双击下载好的 `Docker Desktop Installer.exe`，一路点 **Next / Ok**，
   看到 **Install** 就点，等待安装完成（约 3~5 分钟）。
3. 安装程序提示重启时，**重启电脑**。
4. 重启后从开始菜单启动 **Docker Desktop**，第一次会弹服务条款，勾选 **Accept**。
5. 等左下角的状态从 `Starting...` 变成绿色的 **Engine running**（约 1~3 分钟）。

> 请安装**最新版** Docker Desktop（4.34 及以上，引擎 25+）。
> 部署包里的镜像是用较新的 Docker 构建的，版本太老的 Docker 可能导入失败。

> **如果提示要装 WSL 或提示"WSL kernel version too low"**：
> Docker Desktop 会弹一个链接，点它按提示装 WSL2 更新包，装完重启即可。
> 也可以手动：开始菜单搜"启用或关闭 Windows 功能" → 勾选
> 「适用于 Linux 的 Windows 子系统」和「虚拟机平台」→ 重启。

> **公司/学校的电脑**：如果安装时提示需要管理员权限或提示被策略禁止，
> 需要找 IT 开通；这是 Docker 安装本身的限制，与本项目无关。

## 2. 把部署包拷到目标电脑

部署包是一个文件夹 **`Forzh-Deploy`**，里面大概是这样：

```
Forzh-Deploy\
    一键部署.bat        ← 只有它需要双击
    停止服务.bat
    查看日志.bat
    先看我-三步部署.txt
    部署说明.md         ← 本文档
    docker-compose.deploy.yml
    deploy.ps1
    .env.example
    images\             ← 两个镜像文件，共约 225 MB，不能少
    whisper-model\      ← 语音模型，约 145 MB，不能少
```

注意事项：

- **必须整个文件夹一起拷**，`images` 和 `whisper-model` 少一个都跑不起来。
- 建议放在 **`D:\Forzh-Deploy`** 这种**纯英文短路径**下。
  不要放在中文路径、桌面、U 盘、OneDrive/网盘同步目录里（会导致文件被锁或路径解析失败）。
- 拷贝可以用 U 盘、移动硬盘、局域网共享，或者用压缩包传过去再解压。
- 不要"只拷 .bat 文件"，脚本要靠同目录的其它文件工作。

## 3. 双击「一键部署.bat」

双击后会弹出一个命令行窗口，脚本会依次自动完成：

1. 检查 Docker 是否在运行（没运行会尝试帮你启动，最多等 4 分钟）；
2. 导入镜像（第一次约 1~3 分钟，会显示进度）；
3. 检查语音模型是否就位（随包提供，不会下载）；
4. 端口被别的程序占用时自动换一个；
5. 启动两个容器（网页 + 接口）；
6. 等服务就绪后**自动打开浏览器**；
7. 打印"部署完成"和一个网址。

看到下面这几行就成功了（地址以窗口里打印的为准，端口被占用时可能是 8081 等）：

```
部署完成！
使用地址：http://127.0.0.1:8080/
```

### 之后怎么用

- **上课**：打开浏览器，访问 <http://127.0.0.1:8080/>。
  建议存成收藏夹，或在桌面建一个快捷方式（右键 → 新建 → 快捷方式 → 粘贴地址）。
- **服务是常驻的**：关掉命令行窗口、关掉浏览器都不影响。
- **开机自动恢复**：Docker Desktop 默认开机自启，容器设置为
  `unless-stopped`，所以重启电脑后服务会自动回来（等 Docker 转绿后再打开网页）。
  如果重启后页面打不开，先看一眼 Docker Desktop 是不是没启动。
- **停止服务**：双击 `停止服务.bat`（数据不会丢）。
- **排查问题**：双击 `查看日志.bat`，把输出发给我。

## 4. 首次使用：填 Key、开权限

打开页面后，按下面的顺序花 2 分钟配置一次，之后就不用再管了。

### 4.1 打开设置

点页面**左上角的图标** → 全局设置。

### 4.2 对话和图片（可跳过）

| 想达到的效果 | 设置里怎么选 | 是否需要 Key |
| --- | --- | --- |
| 完全离线、不花钱 | 对话服务选 **内置模板**，图片服务选 **Mock** | 不需要 |
| 让孩子和"未来的自己"真聊起来 | 对话服务选 **硅基流动**，填 Key | 需要 |
| 生成真正的梦想卡插画 | 图片服务选 **硅基流动**，填 Key | 需要 |

- Key 在 <https://cloud.siliconflow.cn/> 注册后创建，注意账户余额。
- Key 保存在本机（Docker 卷 `forzh_app-data` 里的 `settings.json`），
  不会上传到别的地方，也不会回显在网页上。
- 不填 Key 也能完整走完流程，只是对话是模板话术、图片是占位图。
  **建议先不填 Key 跑一遍完整流程**，确认摄像头、麦克风、出图流程都正常，再填 Key。

### 4.3 语音识别

- 默认已选 **本地 Whisper**（模型随包提供，不需要联网下载）。
- 如果上课电脑很快、想更准，可以在设置里换 `small`，但换模型需要联网下载一次。
- 也可以用浏览器自带识别，但它依赖 Chrome 联网，教室里不推荐。

### 4.3.1 语音播报（声音好不好听看这里）

默认使用 **CosyVoice2 神经网络音色**（硅基流动），和浏览器自带的机械音差别很大。

- **需要 Key + 联网**：语音播报走硅基流动，按字符计费；没有 Key 或断网时，
  页面会自动回退到浏览器语音，流程不会中断。
- **音色**（设置 → 语音播报 → 音色）：
  - 女声：`bella`（激情）、`claire`（温柔）、`diana`（欢快）、`anna`（沉稳）
  - 男声：`alex`（沉稳）、`benjamin`（低沉）、`charles`（磁性）、`david`（欢快）
  - 给孩子讲故事，`claire` / `bella` 最常用；男老师可用 `alex`。
- **语气**（设置 → 语音播报 → 语气）：
  - `warm` 温柔亲切（像幼儿园老师，默认）
  - `lively` 活泼有惊喜感（暖场、互动环节）
  - `calm` 平静柔和（睡前故事、收尾）
- **语速**由语气决定，可以在 `.env` 里改 `SILICONFLOW_TTS_TONE` 默认值。
- 想完全离线：把语音播报切回**浏览器**，音质会退回机器音，但不花钱、不联网。

### 4.4 摄像头和麦克风

- 第一次点"开始录音"或"拍照"时，浏览器会弹权限请求，点 **允许**。
- 如果误点了"阻止"：点地址栏左边的锁图标 → 把摄像头/麦克风改成"允许" → 刷新页面。
- 摄像头黑屏：检查是不是被钉钉/腾讯会议/相机应用占用了，关掉再试。
- **必须用 `http://127.0.0.1:8080/` 或 `http://localhost:8080/` 打开**，
  换成 `http://192.168.x.x:8080/` 浏览器会禁用摄像头和麦克风（安全限制）。

### 4.5 建议先做一次验收

1. 走一遍课堂模式：设备检查 → 三轮访谈 → 拍照/不拍照 → 生成梦想卡 → 和未来的自己聊两句；
2. 点"下载"看梦想卡能不能保存；
3. 点"下一位小朋友"，确认能回到开始页。

## 5. 常见问题

### 双击后窗口一闪就没了 / 提示"不是内部或外部命令"

Windows PowerShell 被执行策略拦住了。改用手动方式：

1. 在文件夹空白处按住 **Shift + 右键** → **在此处打开 PowerShell 窗口**；
2. 输入：`powershell -ExecutionPolicy Bypass -File .\deploy.ps1` 回车。

### 提示"Docker 引擎仍未就绪"

- 看任务栏右下角有没有 Docker 的小船图标，点开等它变绿；
- 刚装完 Docker 必须**重启一次电脑**；
- 提示 WSL 相关错误 → 按第 1 步的 WSL 说明处理；
- 还不行：Docker Desktop → 右上角齿轮 → Troubleshoot → **Restart**。

### 提示"端口 8080 / 8000 被占用了"

不用管，脚本会**自动换一个没被占用的端口**继续部署，并打印新的地址，例如：

```
[注意] 端口 8080 被其他程序占用，已自动改用 8081。
使用地址：http://127.0.0.1:8081/
```

自动选中的端口会写进 `Forzh-Deploy\.env`，以后都用这一组，不会每次都变。
如果你之前用开发模式（`npm run dev` + `uvicorn`）在这台电脑上跑过本项目，
8000 端口十有八九被那个 uvicorn 占着，部署时就会自动换到 18000，
网页本身不受影响（网页通过容器内网访问接口）。

想固定端口：用记事本改 `.env` 里的 `WEB_PORT` / `API_PORT`，保存后重新双击 `一键部署.bat`。

### 网页能打开，但页面空白 / 一直转圈

1. 先按 **Ctrl + F5** 强制刷新；
2. 双击 `查看日志.bat`，看 `api` 有没有报错；
3. 确认 `images` 和 `whisper-model` 文件夹都在、没被安全软件删掉。

### 语音识别没反应 / 提示"语音识别不可用"

- 设置里确认语音识别是**本地 Whisper**；
- 第一次识别要加载模型，**等 1~3 秒**是正常的；之后每句话大约 **0.5 秒**出结果
  （实测：i5 级别 CPU、base 模型、4 秒中文语音 = 0.5 秒）；
- 如果提示要下载模型，说明 `whisper-model` 文件夹丢了，把部署包里的这个文件夹重新拷进去，然后双击一次 `停止服务.bat` → `一键部署.bat`。

> 实测结果（base + int8，CPU）：完全断网、模型只读挂载的情况下，
> 冷启动首次转写约 2 秒（含模型加载），之后每句约 0.5 秒。
> 识别准确率一般，专业词（如"宇航员"）可能写成"与航员"；课堂场景够用，
> 想更准可在设置里换 `small`（需要联网下载一次，约 460 MB，速度约慢 2 倍）。

### 拍照一直是黑的

- 浏览器地址必须是 `127.0.0.1` / `localhost`；
- 关掉其它占用摄像头的软件（会议、相机、OBS）；
- 换 Chrome / Edge 试试（不要用 IE 内核浏览器）。

### 生成梦想卡很慢或失败

- 用 Mock 图片是瞬间出图；用硅基流动要 5~20 秒，慢是正常的；
- 课堂时间紧时，在照片页选"快速卡通"；
- 页面现在会直接告诉你失败原因，照着提示做即可：

| 页面提示 | 意思 | 怎么办 |
| --- | --- | --- |
| 这张照片被服务方内容审核拦下了… | 硅基流动把儿童照片误判了（**不是你操作错**，同一张照片重试常常就通过） | 点「重新生成」；或换一张更清楚的正脸照；或改用「卡通形象」 |
| 生成超时了… | 照片保脸要跑两步，审核重试把时间拖长了 | 点「重新生成」，或改用「卡通形象」 |
| 硅基流动 API Key 无效或已过期 | Key 填错或被删了 | 打开全局设置重新填 Key |
| 硅基流动账户余额不足或调用太频繁 | 账户没钱或短时间调太多 | 充值，或等几分钟 |
| 照片太大了（超过 4MB） | 手机原图太大 | 重拍一张，或换一张更小的照片 |

> **为什么会"被审核拦下"**：照片模式用的是图像编辑模型（Qwen-Image-Edit），
> 服务商对真实人脸（尤其是儿童）做了防伪造审核，判定是概率性的，会出现
> "同一张照片这次拦、下次过"的误判。后端已经会自动重试几次，仍然失败才会提示。
> 想稳、想快，课堂上优先用「卡通形象」或「不使用照片」——这两条走纯文生图，
> 几乎不会触发审核。

### 磁盘占用越来越大

Docker 占用约 2~3 GB。想清理：

```
docker system prune -a
```

⚠️ 不要加 `--volumes`，那会**删掉设置里的 API Key**。

### 断电/异常关机后打不开

双击 `查看日志.bat`；如果容器状态异常，双击 `停止服务.bat` 再 `一键部署.bat` 即可，
数据（Key、设置）不会丢。

## 6. 升级到新版本

1. 拿到新的 `Forzh-Deploy` 文件夹（或压缩包），解压到别的位置；
2. **先双击旧包的 `停止服务.bat`**（保留数据）；
3. 把新包里的 `images`、`whisper-model`、脚本覆盖到原来的 `D:\Forzh-Deploy`；
4. 双击 `一键部署.bat`。

> 只覆盖文件，不要删掉 `D:\Forzh-Deploy\.env`（那是你的端口配置）。
> 设置里的 API Key 存在 Docker 卷里，升级不受影响。

## 7. 备份 / 换电脑 / 卸载

**备份设置（含 API Key）**

```
docker run --rm -v forzh_app-data:/data -v "%cd%":/backup forzh-api:latest tar czf /backup/forzh-data.tgz -C /data .
```

在 `Forzh-Deploy` 目录里执行，会生成 `forzh-data.tgz`。
这里用的是部署包自带的 `forzh-api` 镜像（里面已经有 tar），**断网也能用**。
恢复时把 `-v "%cd%":/backup` 不变，命令换成解包：

```
docker run --rm -v forzh_app-data:/data -v "%cd%":/backup forzh-api:latest tar xzf /backup/forzh-data.tgz -C /data
```

**换一台电脑**

把整个 `Forzh-Deploy` 文件夹 + `forzh-data.tgz` 拷过去，按本文档装好 Docker，
先导入镜像（双击 `一键部署.bat`），再用上面的恢复命令还原设置。

**卸载**

```
cd D:\Forzh-Deploy
docker compose -f docker-compose.deploy.yml down -v
```

然后再卸载 Docker Desktop（设置 → 应用 → Docker Desktop → 卸载）。
`-v` 会删掉全部数据，确定不需要 Key 和设置再执行。

## 8. 安全与隐私（请务必看）

- 服务**只监听本机回环地址**（`127.0.0.1`），同一局域网里的其它电脑访问不到，
  这是故意设置的：本项目没有账号体系，直接暴露到局域网/公网等于把设置面板
  （含 API Key）公开。
- 孩子的声音只在**本机**转写，录音转写完即删除；照片不会上传到图片服务，
  除非老师/家长在页面上明确选择使用照片并确认发送。
- 开启在线模型后，会发送**文字**（访谈回答、对话内容、已确认的角色/场景文字）
  到硅基流动，计费和数据留存按对方政策执行。
- API Key 明文保存在本机 Docker 卷里，能登录这台电脑的人就能看到。
  不要把 Windows 账号密码共享给不需要的人。
- 如果确实需要局域网多台电脑访问，需要额外的反向代理 + HTTPS 证书，
  并且必须先加访问控制，**不要直接把端口改成 0.0.0.0**。

## 附：给维护者（重新打包）

在开发机上（已装 Docker Desktop、`backend\data\whisper` 里有模型缓存）：

```powershell
# 在仓库根目录
powershell -ExecutionPolicy Bypass -File .\scripts\build-deploy-bundle.ps1 -Version 1.0.1
# 需要压缩包时加 -Zip；不想重新构建镜像时加 -SkipBuild
```

产物：`dist\Forzh-Deploy\`（约 360 MB），以及可选的
`dist\Forzh-Deploy-<版本>.zip`。

部署包构成：`forzh-api` / `forzh-web` 两个镜像的 `docker save` 产物 +
`deploy\` 下的脚本与文档 + 预置的 Whisper base 模型缓存。
